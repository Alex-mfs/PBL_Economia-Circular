# Base de Dados — TáNaValidade

Modelo relacional desenvolvido em MySQL Workbench, no âmbito do projeto PBL de Economia Circular.

## Ficheiros

- `Diagrama-TáNaValidade.mwb` — modelo da base de dados, para abrir no MySQL Workbench.
- [Modelo da base de dados](MODELO_BASE_DADOS.md) — estrutura e atualização do modelo.

## Objetivo

Organizar a informação necessária ao funcionamento do TáNaValidade, uma aplicação que ajuda a controlar a validade dos alimentos e a reduzir o desperdício alimentar.
